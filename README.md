# Parity

An interactive archive of 17 women whose scientific credit was taken, erased or handed to someone else. Open a file, check the evidence, put her name back.

## Run it

It's a static site: open `index.html` in a browser, or publish it with GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / root).

## What's in this release

- **Portraits**: each scientist's photo is loaded from Wikipedia at the reveal. Only freely licensed Wikimedia Commons images are shown, with a credit link.
- **Sound**: an optional ambient soundtrack generated in the browser. Off until the player turns it on.
- **Smoother flow**: soft transitions between steps, story scenes that play on by themselves, a drawer that opens on arrival, and a "Pull all three" shortcut for exhibits.

Progress is saved in the visitor's browser.
